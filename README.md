# ✅ To-Do List (C++ Console Application)
A simple and interactive console-based To-Do List application written in C++. This project allows users to manage daily tasks efficiently using basic operations like add, view, complete, and remove tasks.

📋 Features
➕ Add new tasks

📄 View all tasks

✔️ Mark tasks as completed

❌ Remove tasks from the list

🚫 Maximum of 100 tasks

🧾 How It Works
The program uses a class-based structure:

Task class to represent each task with a description and completion status.

ToDoList class to manage a fixed-size array of tasks.

Tasks can be added, viewed, completed, and deleted through a menu-driven interface.
